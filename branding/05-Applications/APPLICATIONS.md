# Application directions

- **Website:** dark hero, horizontal wordmark, concise tagline, product suite grid.
- **GitHub:** use the standalone capybara mark as avatar; keep repository graphics monochrome.
- **README:** vertical lockup or centered mark, followed by a one-sentence product description and quick-start section.
- **Favicon:** use the simplified standalone capybara silhouette; test at 16, 32 and 48px.
- **Social:** use the mascot on a solid ink or paper field; keep copy short.
- **Documentation:** paper background, ink typography, JetBrains Mono for code and metadata.
- **Dashboard:** charcoal navigation, paper/soft-gray surfaces, clear status colors only where functional.
- **Merchandise:** single-color mark on black or white apparel and accessories.
