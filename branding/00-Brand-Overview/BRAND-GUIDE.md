# CappyCorp — Brand identity system

## Brand idea
A calm, curious engineering company building useful software. The capybara is the recognizable anchor: observant, adaptable, composed and quietly distinctive.

## Positioning
Independent technology company creating software products, developer tools, infrastructure and experimental projects.

## Personality
Engineering-driven · Independent · Curious · Approachable · Reliable · Developer-focused

## Voice
Clear, direct, useful and quietly confident. Prefer concrete language over hype. Write primarily in English.

## Tagline
**Stay curious. Build useful things.**

Alternatives:
- Quietly building useful things.
- Curious by nature. Useful by design.
- Tools for people who build.
- Independent minds. Useful software.

## Logo use
- Prefer the horizontal lockup for headers and navigation.
- Use the vertical lockup for centered compositions and profile artwork.
- Use the standalone mark for app icons, favicons and compact spaces.
- Maintain clear space equal to the capybara eye-to-snout distance around the mark.
- Never stretch, outline, add gradients, or place the mark on low-contrast backgrounds.

## Color
Ink `#0B0B0B`, charcoal `#2A2A2A`, mid gray `#6B6B6B`, soft gray `#E5E5E5`, paper `#FFFFFF`.
Monochrome is the default; product differentiation should come from naming, iconography and restrained accents rather than unrelated palettes.

## Typography
Display and UI: Suisse Intl where licensed, otherwise Inter.
Code and technical metadata: JetBrains Mono.
Use compact tracking for large headlines; prioritize legibility in documentation and dashboards.

## Layout
Use an 8px base spacing rhythm. Core spacing scale: 4, 8, 12, 16, 24, 32, 48, 64, 96px.
Use 8px, 12px and 20px corner radii. Prefer generous negative space and precise alignment.

## Pattern and iconography
Use low-contrast repeating capybara silhouettes, cropped contour lines and simple technical symbols.
Icons should be geometric, consistent in stroke weight, and readable at 16–24px.

## Product architecture
CappyBar — technical search.
CappyStack — developer tools and infrastructure.
CappyDev — developer tools.
CappyLabs — research in Rust, AI and systems.
CappyWatch — monitoring and observability.
CappyWebhook — webhook debugging.

All products share the parent wordmark logic, monochrome palette, typography and spacing. Product-specific symbols are secondary to the product name.

## Digital applications
Website: dark editorial hero, clear product navigation, concise copy and strong typography.
GitHub: monochrome avatar, consistent repository banners and README headers.
Documentation: light reading surface, dark code blocks, compact navigation.
Dashboard: high-contrast status hierarchy, restrained data visualization.
Social: centered mascot or mark with short, useful messaging.
Merchandise: one-color mark, generous placement, no decorative effects.
