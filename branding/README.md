# CappyCorp Brand Identity — Asset Pack

This folder contains the initial CappyCorp identity system and editable vector assets.

## Structure
- `00-Brand-Overview/` — brand guide and visual overview
- `01-Logo/` — primary mark and horizontal/vertical light/dark lockups
- `02-Mascot/` — institutional, expressive and favicon mascot SVGs
- `03-Product-Identities/` — individual identity cards for all six products
- `04-Design-System/` — design tokens and CSS variables
- `05-Applications/` — application guidance

## Notes
SVG assets are editable. The current pack is a foundational first pass: validate the final logo geometry, small-size legibility, font licensing and accessibility contrast before production rollout.
